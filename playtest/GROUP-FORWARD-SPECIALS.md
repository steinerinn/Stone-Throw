# Group forward-specials compatibility clarification (unaccepted candidate)

User authorization: Group Battle Batch 1 responsiveness / forward specials request, 2026-09-15.

Only in active-ring Group play, Scout and Catapult decisions target the owner's normal forward opponent. Dragon, Demon, Wizard, Goblin, Archer, Monk and Necromancer/Plague continue using the predecessor reaction target. Dwarf bonus handling is unchanged.

If the forward target has no surviving required core/activated Hero while the root is still settling, a Scout/Catapult opportunity is retained in the existing next-turn counters. No mid-root target redirection occurs. After the root settles, the normal elimination boundary compresses the ring; the preserved opportunity uses the then-current forward opponent at its next legal turn. Final match completion clears these unusable Scout/Catapult counters. No new pending-state schema, placement rule, RNG stream or shot-budget reset is introduced.

Existing Archer-to-ordinary-shot and Plague suppression compatibility behavior remains unchanged. This clarification does not convert non-Catapult bonuses into new Catapult opportunities.

The pre-pass artifact is frozen outside the served tree at ../responsiveness/before. Historical fixtures/expectations were not rewritten. Six canonical files (three TypeScript sources plus their compiled JavaScript) implement this authorized difference; unrelated canonical, asset and stylesheet bytes remain protected.

Evidence and known physical follow-ups: ../responsiveness/REPORT.md.
